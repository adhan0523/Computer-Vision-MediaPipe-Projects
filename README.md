## 🧠 About This Repository

This repository is a collection of **real-time computer vision projects** that I'm building while learning OpenCV and MediaPipe.

Instead of following only tutorials, I'm using each project to understand how computer vision works in practice—from detecting hands and faces to tracking movement and turning visual input into useful interactions.

Most of the projects are intentionally small and focused. This makes it easier to understand what each part of the system is doing before moving on to something more complex.

## 🚀 Projects

### ✋ Hand Tracking

Projects focused on detecting hands, identifying landmarks, tracking fingers, and understanding hand movement.

**Concepts explored:**

* Hand landmark detection
* Finger tracking
* Landmark coordinates
* Gesture recognition
* Real-time webcam processing

---

### 🙂 Face & Face Mesh

Projects involving facial detection and detailed facial landmark tracking.

**Concepts explored:**

* Face detection
* Facial landmarks
* Face mesh
* Real-time tracking
* Coordinate mapping

---

### 🧍 Pose Estimation

Projects that explore tracking the human body using MediaPipe Pose.

**Concepts explored:**

* Pose landmarks
* Body tracking
* Joint coordinates
* Movement analysis
* Real-time pose estimation

---

### 🖥️ Human-Computer Interaction

Projects that use computer vision as an interface between the user and the computer.

The goal is to experiment with ways visual input can replace traditional mouse and keyboard interactions.

**Concepts explored:**

* Gesture-based control
* Virtual interaction
* Hand-based interfaces
* Vision-based controls
* Real-time interaction
